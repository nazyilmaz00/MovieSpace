# MovieSpace
Bu proje, BLM2537 Ağ Tabanlı Programlamaya Giriş dersi kapsamında geliştirilmiş bir web uygulamasıdır. 
Bu projede kullanıcıların izledikleri filmlerin değerlendirmesini yaptığı ve hesabında arkadaşlık kurduğu kullanıcılarla birlikte filmler hakkındaki fikir alışverişi yaptığı bir site geliştirmek istedim.

## Kullanılan Teknolojiler
* HTML
* CSS
* JavaScript

## Kurulum ve Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:
1. Bu depoyu bilgisayarınıza indirin veya klonlayın (`git clone [Depo URL'sini Buraya Yapıştırın]`).
2. İndirdiğiniz proje klasörünü **VS Code** ile açın.
3. VS Code eklentilerinden **Live Server** eklentisinin yüklü olduğundan emin olun.
4. Klasör içerisindeki "index.html" dosyasına sağ tıklayıp **"Open with Live Server"** seçeneğine tıklayarak projeyi tarayıcınızda çalıştırabilirsiniz.
